# Lupapiste datamodel
This is related to the datamodel update in 2025 where Lupapiste will be
updated to be able to collect Ryhti-compliant data.

An overview of the data model can be found in `overview.puml` and the 
corresponding .png file. 

This is a high-level view created
before the deeper analysis of the Ryhti changes so any info created after it 
takes precedence.

## Building object
The most impactful change by the Ryhti compliance update is to the building schema.
This is all within the `Rakennuskohde` node in the above Lupapiste overview.

For clarity the building data model can be found separately in `building-object.puml` 
and the corresponding .png file.


Lisähuomiot ja integraatiota koskevat muistiinpanot kirjataan tiedostoon [ryhti-notes.md](./ryhti-notes.md).

Tiedoston tarkoitus: kehityksen aikana kertyvien Ryhti-integraatioon liittyvien päätösten, oletusten, tarkennusten ja avoimien kysymysten dokumentointi myöhempää viittausta varten.
