# Password dictionaries

Dictionaries are frequency sorted.

## Firstnames and lastnames

- 400 most common lastnames and firstnames.
- `fi_female_firstname.txt`, `fi_male_firstname.txt`, `fi_lastnames.txt`
- https://www.avoindata.fi/data/fi/dataset/none
- Creative Commons Attribution 4.0 International License

## Common Finnish words

- 400 most common Finnish words, exluded numbers etc.
- `fi_common.txt`
- https://kaino.kotus.fi/sanat/taajuuslista/parole_5000.html
- Creative Commons Nimeä 4.0

## Custom

- Product names like "lupapiste".
- `custom.txt`

## Qwerty

- Finnish keyboard QWERTY-layout
- `fi_qwerty.txt`
