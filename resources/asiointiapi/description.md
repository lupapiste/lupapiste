# AsiointiAPI

Rakennetun ympäristön asiointijärjestelmän ja kuntajärjestelmän integraatiorajapinta.

**Huom**. Rajapintakuvaukset eivät ole lopullisia ja voivat muuttua testauksen ja kehityksen yhteydessä. Erityisesti rajapintametodien kuvauksessa oleva merkintä `[Beta]` indikoi, että suurella todennäköisyydellä rajapintametodi saattaa vielä muuttua.

Rajapinnan toteutus noudattelee _AsiointiAPI Asiointijärjestelmän ja kuntajärjestelmän integraatiot - Vaatimusmäärittely_ dokumenttia, versio 1.1, päiväys 9.12.2025.
